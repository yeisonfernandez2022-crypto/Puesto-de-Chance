# HU-013 · Caducidad de premios no cobrados

| Campo | Valor |
|---|---|
| **ID** | HU-013 |
| **Épica** | Premios |
| **Rol principal** | Sistema (regla de negocio) |
| **Prioridad** | Baja |
| **Estado QA** | ⏳ Pendiente |

## Historia de Usuario

> **Como** administrador del puesto de chance,
> **quiero** que los premios no cobrados caduquen tras el plazo legal,
> **para** no pagar premios vencidos y reflejar el estado real del tiquete.

## Criterios de Aceptación

- [ ] Un premio solo puede cobrarse dentro de `DIAS_CADUCIDAD_PREMIO` (365 días) desde que se jugó el sorteo.
- [ ] Si el plazo venció, el tiquete pasa a estado `CADUCADO` y el pago se rechaza con **410** ("El premio está caducado").
- [ ] Los tiquetes `PAGADO` no se ven afectados por la caducidad.

## Implementación

| Elemento | Detalle |
|---|---|
| Endpoint | `POST /api/v1/tickets/:codigo/pagar` |
| Módulo / Controlador | `src/services/ticketService.js` → `pagarPremio()` (usa `diasEntre` y `DIAS_CADUCIDAD_PREMIO`) |

## Prueba de Calidad

> ⚠️ **Esta historia NO cuenta aún con caso de prueba automatizado.**
> Se requiere un test que simule el paso del plazo (mutando `sorteo.jugadoEn`) y verifique la respuesta **410** y el estado `CADUCADO`.
