## Historia de Usuario

> **Como** vendedor o administrador del puesto de chance,
> **quiero** iniciar sesión con mis credenciales y recibir un token JWT,
> **para** operar la API de forma segura con mi identidad registrada y mi rol asignado.

## Criterios de Aceptación

- [ ] El login exige `usuario` y `password`; si falta alguno responde **400**.
- [ ] Si las credenciales son incorrectas responde **401** con `{"error": "Credenciales inválidas"}`.
- [ ] Si la cuenta está inactiva responde **403** con `{"error": "Usuario inactivo"}`.
- [ ] En éxito responde **200** con el `token` y el perfil del usuario **sin exponer la contraseña**.
- [ ] El token incluye el `id` y el `rol` del usuario y expira según `JWT_EXPIRES_IN` (8 h por defecto).
