## Historia de Usuario

> **Como** administrador del puesto de chance,
> **quiero** registrar el resultado oficial de un sorteo,
> **para** que todos los tiquetes activos del sorteo queden liquidados automáticamente con su premio.

## Criterios de Aceptación

- [ ] Solo un `ADMIN` puede registrar el resultado; otro rol recibe **403**.
- [ ] Para CHANCE el resultado es un número de **4 dígitos**; para BALOTO una jugada completa (5 números + superbalota); formato inválido responde **400**.
- [ ] No se puede registrar el resultado de un sorteo que ya fue jugado (**409**).
- [ ] El sorteo pasa a estado `JUGADO` con la fecha del registro (`jugadoEn`).
- [ ] Todos los tiquetes `ACTIVO` del sorteo reciben su `premio` liquidado (incluido 0 para los que no ganan).
- [ ] Responde **200** con el sorteo actualizado.
