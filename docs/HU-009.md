## Historia de Usuario

> **Como** administrador del puesto de chance,
> **quiero** crear sorteos de Chance o Baloto con nombre y fecha futura,
> **para** tener las jornadas de venta listas antes de que los vendedores operen.

## Criterios de Aceptación

- [ ] Solo un `ADMIN` puede crear sorteos; un `VENDEDOR` recibe **403**.
- [ ] El `tipo` debe ser `CHANCE` o `BALOTO`; otro valor responde **400**.
- [ ] El `nombre` es obligatorio y la `fecha` debe ser válida y **futura** (**400** en otro caso).
- [ ] El `acumulado` solo aplica a sorteos de tipo `BALOTO`.
- [ ] El sorteo se crea en estado `ABIERTO` con id incremental.
- [ ] Los vendedores pueden consultar la lista y el detalle de sorteos disponibles.
