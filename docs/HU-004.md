## Historia de Usuario

> **Como** administrador del puesto de chance,
> **quiero** que las ventas de tiquetes se cierren automáticamente unos minutos antes del sorteo,
> **para** garantizar que ningún tiquete se venda fuera del tiempo reglamentario.

## Criterios de Aceptación

- [ ] No se permite vender tiquetes de un sorteo cuyo estado no sea `ABIERTO` (**409**).
- [ ] No se permite vender cuando faltan menos de `MINUTOS_CIERRE_VENTAS` (15) para el sorteo (**409**).
- [ ] No se permite vender tiquetes de chance en un sorteo de Baloto ni viceversa (**400**).
