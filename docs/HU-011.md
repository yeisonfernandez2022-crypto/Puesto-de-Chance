## Historia de Usuario

> **Como** vendedor del puesto de chance,
> **quiero** que el sistema calcule el premio de cada apuesta según la modalidad y el número de cifras,
> **para** pagar exactamente lo que dicta la tabla de pagos sin cálculos manuales.

## Criterios de Aceptación

- [ ] Tabla de pagos por cifras acertadas: **4 → ×4500**, **3 → ×400**, **2 → ×50**, **1 → ×5**.
- [ ] Modalidad `DIRECTO`: premio solo si el número jugado coincide con las últimas cifras del resultado.
- [ ] Modalidad `COMBINADO`: gana si las últimas cifras del resultado coinciden en cualquier orden y el premio se divide entre las permutaciones únicas del número.
- [ ] Un número con todas las cifras iguales (p. ej. `1111`) no puede jugar `COMBINADO`.
- [ ] Las apuestas que no ganan reciben premio **0**.
