# HU-005 · Anulación de tiquetes dentro de la ventana permitida

| Campo | Valor |
|---|---|
| **ID** | HU-005 |
| **Épica** | Ventas |
| **Rol principal** | Vendedor (dueño) / Administrador |
| **Prioridad** | Media |
| **Estado QA** | ✅ Aprobado |

## Historia de Usuario

> **Como** vendedor del puesto de chance,
> **quiero** anular un tiquete que vendí por error dentro de los minutos permitidos,
> **para** corregir la venta sin afectar la caja de otros días ni tiquetes de otros vendedores.

## Criterios de Aceptación

- [ ] Solo el vendedor dueño del tiquete (o un `ADMIN`) puede anularlo; otro vendedor recibe **403**.
- [ ] La anulación exige un `motivo` obligatorio; sin motivo responde **400**.
- [ ] Solo se anulan tiquetes en estado `ACTIVO`; si ya está pagado/anulado responde **409**.
- [ ] No se puede anular un tiquete de un sorteo ya jugado (**409**).
- [ ] El vendedor solo puede anular dentro de `MINUTOS_ANULACION` (10) tras la venta; fuera de la ventana responde **409**.
- [ ] La anulación queda registrada con usuario, motivo y fecha, y el tiquete pasa a estado `ANULADO`.
